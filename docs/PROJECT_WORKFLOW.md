# Project Workflow

Status: project master foundation only; Phase 3+ pending.

Tender → estimate → won tender conversion → client/contract → project → WBS/BOQ → budget/baseline → procurement commitments → material/labor/equipment/subcontract actuals → IPC/revenue → collections → forecast/profitability/cash flow → close.

Every cost must retain source-document traceability and classification by project and, when applicable, WBS, cost center, cost code, and BOQ item.
