# Accounting Cycle

Status: designed, implementation pending Phase 2 and later phases.

Company setup → chart of accounts → mappings → opening balances → source documents → automatic/manual journals → general ledger → trial balance → adjustments → financial statements → closing → next-year opening.

Only posted, balanced entries in open periods may affect reports. Posted history is immutable; corrections use reversal or controlled adjustment. Phase 1 creates the company, fiscal year, and periods but creates no journal data.
