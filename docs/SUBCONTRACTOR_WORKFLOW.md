# Subcontractor Workflow

Status: core implemented. Subcontractor masters, work certificates, retention, advance recovery, payable posting, and source payment work locally. Detailed subcontracts/BOQ commitments, performance, variations, and retention release remain planned.

Subcontractor → subcontract/BOQ → advance → work certificate → retention and advance recovery → payable → payment → retention release. Certificates affect project actual cost and subledger/GL; signed contract affects committed cost only.
