# دليل المستخدم العربي — الإصدار التجريبي المحلي

## أول مرة أفتح النظام أعمل إيه؟

ابدأ بإنشاء الشركة ثم السنة المالية. اختر طريقة دليل الحسابات، واقرأ تنبيه الربط المحاسبي. يمكنك إضافة ضريبة وخزينة/بنك ومخزن ومشروع أول، أو تأجيلها. راجع صفحة التقدم بعد الإنهاء. لا ينشئ النظام بيانات تجارية من تلقاء نفسه.

## الخطوات المتاحة الآن

1. أدخل اسم الشركة وكوداً فريداً والدولة والعملة.
2. أدخل بداية ونهاية السنة؛ النظام ينشئ فترات شهرية مفتوحة.
3. اختر إنشاء دليل الحسابات يدوياً أو قالباً يحتاج موافقة لاحقة. الحسابات نفسها ضمن المرحلة التالية.
4. عرّف ضريبة أو خزينة/بنك أو مخزناً فقط إذا كانت بياناتك الحقيقية جاهزة.
5. أنشئ مشروعاً أول اختيارياً.
6. أنهِ الإعداد. إذا فشل جزء فلن تُحفظ شركة ناقصة.
7. من مساحة العمل أضف الفروع، بدّل بين الشركات، وراقب نواقص التهيئة.
8. اضغط «نسخة احتياطية» واحفظ ملف JSON خارج المتصفح. «استعادة» تستبدل البيانات المحلية بعد التحقق من الإصدار.

## تنبيهات مهمة

- البيانات موجودة على هذا المتصفح والجهاز فقط، ولا تنتقل لجهاز آخر.
- مسح بيانات المتصفح قد يحذف النظام؛ أنشئ نسخاً دورية.
- ملف المستخدم المحلي ليس تسجيل دخول آمناً.
- لا تسجل معاملات مالية قبل إتاحة دليل الحسابات والربط والترحيل في Phase 2.

## التسلسل الكامل المخطط

بعد Phase 2 وما يلي سيكون التسلسل: الحسابات والربط → الأرصدة الافتتاحية → العملاء والموردون والمشروع والعقد وBOQ والميزانية → PR/RFQ/العروض/المقارنة/PO → الاستلام والفاتورة والدفع → النقل والصرف للمشروع → مقاول الباطن ومستخلصه → مستخلص العميل والتحصيل → القيود والأستاذ وميزان المراجعة والتسويات والقوائم → ربحية وتدفق المشروع → إقفال الشهر والسنة → النسخة الاحتياطية. هذه الخطوات غير المتاحة حالياً موثقة كخطة وليست وظائف مكتملة.
