# دليل المستخدم العربي — الإصدار التجريبي المحلي

## ما المتاح الآن؟

النسخة الحالية تتيح تهيئة الشركة وتشغيل النواة المحاسبية، وإدارة العملاء والموردين ومقاولي الباطن والمشروعات والعقود والمناقصات وBOQ والموازنات وأبعاد التكلفة والتغييرات. كما تعمل الفروع والتبديل والنسخ الاحتياطي والاستعادة.

## أول مرة

1. افتح `/setup` وأدخل اسم الشركة وكودًا فريدًا والدولة والعملة.
2. أدخل بداية ونهاية السنة؛ تُنشأ فترات شهرية مفتوحة.
3. أنهِ الإعداد ثم افتح «دليل الحسابات». أنشئ حساباتك أو وافق صراحة على قالب المقاولات الاختياري.
4. أضف ضريبة أو خزينة/بنك أو مخزنًا أو مشروعًا فقط إن كانت بياناتك الحقيقية جاهزة.
5. أنهِ الإعداد؛ العملية محلية وذرية، فلا تُحفظ شركة ناقصة عند الفشل.
6. أضف الفروع عند الحاجة، وبدّل الشركة من أعلى مساحة العمل.
7. اضغط «نسخة احتياطية» واحفظ JSON خارج المتصفح. الاستعادة تستبدل بيانات ERP المحلية بعد التحقق من الإصدار.

## فهم القائمة

القائمة ليست خارطة طريق ولا تعرض «قريبًا». كل عنصر ظاهر قابل للنقر وله وظيفة حقيقية. ستظهر مجموعات الأعمال الأخرى بعد اكتمال كل دفعة تشغيلية.

## تشغيل المحاسبة

1. من «دليل الحسابات» أنشئ الحسابات أو القالب الاختياري. الحساب التجميعي لا يقبل الترحيل.
2. من «الربط المحاسبي» اختر حساب ترحيل نشطًا لكل غرض متاح؛ لا توجد أرقام حسابات ثابتة.
3. من «الأرصدة الافتتاحية» أدخل سطرين أو أكثر واجعل المدين مساويًا للدائن، ثم احفظ.
4. القيد يبدأ Draft. اضغط اعتماد بعد المراجعة ثم ترحيل. لا يمكن ترحيل قيد غير متوازن أو داخل فترة مغلقة.
5. قبل الترحيل يمكن الإلغاء. بعد الترحيل استخدم عكس لإنشاء قيد مقابل بدل حذف التاريخ.
6. راجع اليومية العامة، ثم اختر حسابًا في الأستاذ، وتحقق من ميزان المراجعة والقوائم.

## المشروعات والعقود

أنشئ العميل، ثم المشروع والعقد بنوعه. يمكن بدء المسار من المناقصة وتحويل الحالة `won` ذريًا إلى مشروع وعقد. أضف BOQ والميزانيات وأبعاد التكلفة؛ لا تدخل القيمة المعدلة للعقد إلا التغييرات المعتمدة.

## دورة التوريدات المخططة

## التوريد والمشتريات المتاحة

1. أنشئ خطة توريد مرتبطة بمشروع وعقد، ثم سجل احتياجات المواد بالكميات والتواريخ.
2. أنشئ PR كمسودة، ثم أرسله واعتمده بالترتيب؛ لا يقبل النظام القفز مباشرة للاعتماد.
3. أنشئ RFQ من PR معتمد واختر الموردين المدعوين. لا يمكن تسجيل عرض لمورد غير مدعو.
4. سجل عروض الموردين وقارن الإجمالي ومدة التوريد، ثم اختر العرض لإنشاء PO واحد. اعتماد PO يمثل التزام شراء، وليس استلامًا أو تكلفة فعلية.

## دورة التوريدات التالية

التزام العميل → عقد توريد → BOQ → خطة واحتياج → مشتريات ومورد (منفذ حتى PO) → استلام أو تسليم مباشر → فحص → إذن تسليم → قبول → فاتورة/مستخلص → تحصيل → ربحية.

تتبع المنظومة مستقبلًا الكميات المتعاقد عليها والمخططة والمطلوبة والمأمور بها والمشتراة والمشحونة والمستلمة والمسلمة والمقبولة والمفوترّة والمحصلة والمرتجعة والمتبقية كلًّا على حدة. التسليم المباشر من المورد للعميل لا ينشئ حركة مخزن وهمية. راجع `SUPPLY_WORKFLOW.md`.

## تنبيهات مهمة

- البيانات على هذا المتصفح والجهاز فقط؛ لا توجد مزامنة سحابية.
- مسح بيانات المتصفح قد يحذفها؛ أنشئ نسخًا احتياطية دورية.
- ملف المستخدم المحلي ليس تسجيل دخول أو صلاحيات إنتاجية.
- سجّل فقط قيودك الحقيقية؛ النظام لا ينشئ أرقامًا أو أرصدة تلقائية.
- كل أرقام ورسومات الصفحة التسويقية أمثلة عرض فقط ولا تُحفظ في IndexedDB.
